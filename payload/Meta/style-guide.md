# 写作风格指南（研究者填写；写作与精修必须遵守）

> 未填写的项，AI 使用中性学术文风，并在需要时用 `⟦问：…⟧` 询问，不替研究者设定偏好。

## 语言与文风
- 主语言：中文（保留标准英文术语）
- 句式偏好：待定
- 避免：夸大（“显著改变”“彻底”）、无来源的断言（“众所周知”）、把相关写成因果

## 术语表（中英对照与固定译法）
| 英文 | 固定译法 | 备注 |
|---|---|---|
| tax compliance | 税收遵从 | |
| tax administration | 税收征管 | |
| third-party information reporting | 第三方信息报告 | |

## 引用与格式
- 正文引用格式：待定（目标期刊要求为准）
- 数字与统计量写法（小数位、显著性标注、标准误位置）：待定
- 表格与图的注释写法：待定

## 因果措辞分级（默认；研究者可改）
| 识别状态 | 允许的措辞 |
|---|---|
| 已通过识别审查、假设可辩护 | “…导致/提高/降低…”，并同时给出 estimand 与适用人群 |
| 识别部分成立、存在未排除威胁 | “…与…相关；在…假设下，估计表明…” |
| 仅相关性 | “…与…相关”，不使用因果动词 |

## 文风校准（Style Calibration）与去 AI 味清单（Writing Quality Check）
- **作者样本锚定（研究者可贴入代表作段落或指定期刊）**：待定（若未填写，采用《经济研究》/ AER 克制、精准、少形容词的实证/理论语域）。
- **去 AI 味负面清单**（成稿与精修必须自检并删改）：
  1. 禁用高频机械过渡与空洞套话：“值得注意的是”“综上所述”“不仅如此”“总而言之”“具有重要意义”“引发了广泛关注”“delve into”“underscores the importance”。
  2. 禁用机械三段论或对称排比替代经济逻辑（每段应围绕一个具体主张、识别机制或实证证据展开）。
  3. 禁用无主语或无来源的权威断言（“学界普遍认为”“大量研究表明” → 必须改为具体 `[@key]`）。
  4. 禁用“事实性显著”与“统计显著”混用：必须同时报告经济量级（单位/均值占比）与统计精度，不得只写“显著影响”。
