# 写作风格指南（研究者填写；写作与精修必须遵守）

> 未填写的项，AI 使用中性学术文风，并在需要时用 `⟦问：…⟧` 询问，不替研究者设定偏好。

## 语言与文风
- 主语言：中文（保留标准英文术语）
- 句式偏好：待定
- 避免：夸大（“显著改变”“彻底”）、无来源的断言（“众所周知”）、把相关写成因果

## 术语表（中英对照与固定译法）
| 英文 | 固定译法 | 备注 |
|---|---|---|
| tax compliance | 税收遵从 | |
| tax administration | 税收征管 | |
| third-party information reporting | 第三方信息报告 | |

## 引用与格式
- 正文引用格式：待定（目标期刊要求为准）
- 数字与统计量写法（小数位、显著性标注、标准误位置）：待定
- 表格与图的注释写法：待定

## 因果措辞分级（默认；研究者可改）
| 识别状态 | 允许的措辞 |
|---|---|
| 已通过识别审查、假设可辩护 | “…导致/提高/降低…”，并同时给出 estimand 与适用人群 |
| 识别部分成立、存在未排除威胁 | “…与…相关；在…假设下，估计表明…” |
| 仅相关性 | “…与…相关”，不使用因果动词 |

## 章节写作默认要点（借鉴 econ-writing 类指南；以目标期刊要求为准，研究者可改）
- 摘要：先写发现，再写数据与识别策略；不评价他人文献。
- 引言：尽早进入问题与主要结果（含量级）；文献写成“前人做了什么、还缺什么、本文补什么”的叙述；路线图按本文具体内容写。
- 结论：简短；换一种说法重述发现；不引入新结果；延伸方向写具体做法。
- 破折号等标点习惯由作者和期刊决定；AI 不为“显得像人写的”而刻意添加粗糙或标点。

## 新政治经济学视角（涉及政府行为、制度变革或政策执行的论文适用；研究者可改）
> 起草（`/paper-outline`、`/paper-draft`）与审稿（`/academic-review`）按下列要求核对，并与 `Meta/research-standards.md` 的识别与证据要求并用。

1. **行为者与激励**：写明谁决策、谁受益、谁承担成本，以及决策者的目标、约束与信息（晋升考核、财政压力、央地分权、预算约束、利益集团）；不默认政府是仁慈的计划者。
2. **政策内生性**：先解释政策为何此时此地出现、谁被选入处理组，再谈 estimand；外生性主张须有制度依据，并配预趋势、安慰剂等检验，讨论选择进入与反向因果。
3. **规则与执行**：区分制度条文（de jure）与实际执行（de facto），法条、文号与实际征管强度分开写；二者的落差本身可能是机制。
4. **竞争性解释**：政治动机（策略性执行、寻租、政绩诉求）与经济动机（效率、收入最大化）并列，各给出可区分的检验预测，不用单一叙事收束全文。
5. **机制落到渠道**：写明哪类行为者的什么行为、经哪条渠道、在哪些异质性上更强，并检验与替代渠道的区别。
6. **实证与规范分开**：福利、公平等规范判断另段写，注明所依赖的价值假设与分配权重；不以立场化措辞替代证据。
7. **制度背景与外部效度**：用一小节交代制度背景（如分税制改革）与时点特殊性；推广到制度不同的情形须有依据。
8. **来源纪律**：政策文件、机构沿革、官员与党政信息注明发文机关、文号、日期；无法核实的标 `unverified`（沿用红线 3、6）。

## 文风校准（Style Calibration）与去 AI 味清单（Writing Quality Check）
> 可扫描的套话清单在 `Meta/ai-tells.json`（可自行增删）；`/paper-polish` 使用它，且不用于规避 AI 检测。
- **作者样本锚定（研究者可贴入代表作段落或指定期刊）**：待定（若未填写，采用《经济研究》/ AER 克制、精准、少形容词的实证/理论语域）。
- **去 AI 味负面清单**（成稿与精修必须自检并删改）：
  1. 禁用高频机械过渡与空洞套话：“值得注意的是”“综上所述”“不仅如此”“总而言之”“具有重要意义”“引发了广泛关注”“delve into”“underscores the importance”。
  2. 禁用机械三段论或对称排比替代经济逻辑（每段应围绕一个具体主张、识别机制或实证证据展开）。
  3. 禁用无主语或无来源的权威断言（“学界普遍认为”“大量研究表明” → 必须改为具体 `[@key]`）。
  4. 禁用“事实性显著”与“统计显著”混用：必须同时报告经济量级（单位/均值占比）与统计精度，不得只写“显著影响”。
